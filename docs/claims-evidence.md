# Claims evidence — every number on nzamuwe.com, with a way to check it

Rule enforced on this site: **if a claim can't be traced to a source, it
doesn't ship.** Each row below lists the claim as it appears on the page, the
source, and a copy-paste command a third party can run today.

Verification types:
- **[grep]** — verifiable by anyone, right now, with one command against the live repo.
- **[rerun]** — reproducible by running the project's public pipeline (the artifact is generated, not committed).
- **[resume]** — sourced from Prince's résumé (Oct 2026 draft); owner-verified, not independently fetchable online.
